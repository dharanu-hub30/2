WIND WAVE WEBSITE  (Harnessing wind energy for smart cities)

Files
  index.html                        Media Elements page (home page; must keep this name for Vercel)
  windwave-application-form.html    Application Form page
  windwave-styles.css               Styles for both pages
  windwave-script.js                YouTube loader and form script
  assets/                           audio, video, poster, PDF and banner files

Run locally in VS Code: right-click index.html > Open with Live Server.

YouTube: open windwave-script.js and paste a video ID into YOUTUBE_VIDEO_ID.

Deploy: put index.html and the other files at the TOP LEVEL of a GitHub
repository (not inside a folder), then import that repository in Vercel.
Framework Preset: Other. Leave Build Command and Output Directory empty.
